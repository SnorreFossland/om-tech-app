# Process List (IRTV Context)

### 1. SessionLifecycle workspace
- **Information:** Session record, Closure report
- **Roles:** Facilitator, Student
- **Tasks:** Create session, Close session
- **Views:** Session dashboard

### 2. SessionSetup workspace
- **Information:** Template spec
- **Roles:** Program lead, Instructional designer
- **Tasks:** Configure templates, Set group rules
- **Views:** Setup view

### 3. SessionExecution workspace
- **Information:** Iteration artifact
- **Roles:** Group lead, Minutes representative
- **Tasks:** Run plenum, Facilitate iteration
- **Views:** Execution view

### 4. ArtifactIteration workspace
- **Information:** Artifact record
- **Roles:** Developer, Repo maintainer
- **Tasks:** Create artifact, Link commit
- **Views:** Artifact view

### 5. FeedbackAssessment workspace
- **Information:** Assessment record
- **Roles:** Assessor, Moderator
- **Tasks:** Collect assessments, Aggregate scores
- **Views:** Assessment view

### 6. IntegrationSync workspace
- **Information:** Connector metadata
- **Roles:** Integration admin, Support engineer
- **Tasks:** Sync users, Manage webhooks
- **Views:** Integration view

### 7. ComplianceAuditing workspace
- **Information:** Consent record
- **Roles:** DPO, Auditor
- **Tasks:** Capture consent, Record audit
- **Views:** Compliance view

### 8. AnalyticsReporting workspace
- **Information:** KPI report
- **Roles:** QA analyst, Program analyst
- **Tasks:** Run analytics, Publish report
- **Views:** KPI view

### 9. Onboarding workspace
- **Information:** Training plan
- **Roles:** Trainer, Learner
- **Tasks:** Deliver workshop, Provide guides
- **Views:** Onboarding view

### 10. IncidentResponse workspace
- **Information:** Incident record
- **Roles:** Support lead, Oncall engineer
- **Tasks:** Triage incident, Remediate
- **Views:** Incident view
